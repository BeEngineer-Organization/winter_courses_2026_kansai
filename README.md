# BeEngineer 2026 冬の講習会 関西版 LP

京大本校・梅田校の会員生と保護者向けの、2026年冬の講習会案内ページです。プログラミング経験のある一般生、過去に BeEngineer のイベントへ参加した一般生も対象に含みます。

HTML / CSS / Vanilla JavaScript の静的サイトです。ビルドは不要です。GitHub Pages では `main` ブランチのルートを公開元にします。

## プレビュー

`index.html` をブラウザで開くか、このフォルダで次を実行します。

```bash
python -m http.server 5500
```

ブラウザで `http://localhost:5500` を開きます。

## いま準備中のもの

掲載済みなのは、次の3講座だけです。ほかの講座は、確定してから追加します。

| ID | 校舎 | 講座名 | 日数 | 税込受講料 | 複数申込（税込） |
|---|---|---|---|---|---|
| `course-typing` | 京大本校 | JavaScript でタイピングゲームを作ろう！ | 2日間 | 32,000円 | 未指定 |
| `course-python-3d` | 梅田校 | Python で 3D ゲーム開発 | 1日 | 16,000円 | 12,000円 |
| `course-sudoku` | 梅田校 | 機械学習で数独（ナンプレ）を攻略しよう | 1日 | 16,000円 | 12,000円 |

日程は2026年12月19日（土）・20日（日）です。各日とも 14:00〜16:00 と 16:30〜18:30 を掲載しています。時間帯を選ぶのか両方参加するのかは、確認できるまで書きません。

掲載中の金額はすべて税込です。まだ準備中なのは、参加条件、複数申込の適用条件、JavaScript でタイピングゲームを作ろう！の複数申込料金、申込フォーム URL、キャンセル条件、問い合わせ先、講習会全体の期間です。数独講座に 24,000円・18,000円は使いません。

- 地色 `#f1faff`、文字 `#00134d`、青 `#0072ff`〜シアン `#00bee8` のグラデーション
- 黄色ボタン＋濃紺のずらし影、黄色の切り欠きタグ、傾いた黄色・水色のライン
- 校舎色：京大本校 `#5fdb7c`（緑）、梅田校 `#ffb2ce`（ピンク）。チップ・見出し・日程カードの線に使う

講座は1件ずつ縦に並べ、PCでは「画像｜本文」の2列です。スマートフォンではカードを「講座名・写真・詳細を見る」に絞り、タップすると詳細（タグ・写真・紹介文・開催日・時間・受講料）をモーダルで表示します。モーダルの中身はカードのHTMLをそのまま複製しているので、講座の編集はカード側だけで済みます。料金表は520px未満で「講座名／2つの料金」の2段表示に切り替わります。スマートフォン下部の固定ボタンは、FVの申込ボタンを上へ通り過ぎてから現れ、お申し込み欄（講座ごとの申込ボタン）が画面に見えている間は隠れます（ページを開いた直後にFVの文章を隠さないため）。

## 演出

`assets/js/motion.js` と、`style.css` の「演出」セクションで動かしています。

| 演出 | 場所 |
|---|---|
| ページを開くと順に登場（校舎チップが弾む、「冬の講習会」の水色の帯が伸びる、写真が帯に乗って入る、リボンが落ちてくる） | FV |
| 雪が降る（FVが画面外・タブ非表示のときは止まる） | FV |
| 写真がマウスの方へ少し傾く（PCのみ） | FV |
| 講座カードがフェードインする（講習会紹介はこれだけ） | 講習会紹介 |
| スクロールで現れる（見出し、料金の行、日程カード、絞り込みボタン） | 料金・スケジュール |
| 日付ブロックがくるっと回って出る | スケジュール |
| 斜めのラインが左から引かれる／申込欄に光が通る | 区切り・申込欄 |
| スクロール位置の進捗バー | ヘッダー上端 |

- OSで「視差効果を減らす」を選んでいる人には、進捗バー以外は一切動きません（`<head>` のスクリプトが `.js-motion` を付けないため）。
- 隠す処理は `motion.js` が行うので、JavaScript が読み込めなくても内容はすべて表示されます。
- 演出をやめるときは、`index.html` の `motion.js` の読み込みを消します。対象を増やすときは `motion.js` の `groups` に `[セレクター, "fade" | "up" | "left" | "right" | "zoom", 順番に遅らせるか]` を足します。

## ハロウィン仕様

URLに `?theme=halloween` を付けて開いたときだけ出る演出です。付けないアクセスでは、ハロウィン用のファイルは読み込まれません。

- 配布用URL：`（公開URL）/?theme=halloween`

| 順番 | 内容 |
|---|---|
| 1 | 画面が真っ黒になり、カボチャのお化けの目と口だけが白く浮かんで笑う（約2.3秒） |
| 2 | 黒い画面が中心からコウモリになって飛び立ち、LPが現れる（約2秒） |
| 3 | その後もFVに飾りが残る：写真の角からのぞくカボチャ、飛ぶコウモリ、オレンジと紫の雪、ヘッダー上端の線の色、FVとフッターの角のクモの巣、巣からぶら下がって揺れるクモ |
| 4 | スクロールの途中で各1回だけ：講習会紹介で右端からカボチャがひょこっと出る／料金でコウモリの群れが斜めに横切る／スケジュールで左端からカボチャ／フッターでコウモリの群れが逆向きに横切る（カボチャはタップすると引っ込む） |
| 5 | クモ（＝バグ）が時々ヘッダーの下から糸で降りてきて、揺れてから登っていく（最初は約7秒後、その後30〜45秒おき、最大3回）。タップすると「バグ発見！」と出てつぶれる |

- あえてスキップはできません（最後まで見てもらう演出。約4秒で終わります）。
- 再読み込みのたびに 1・2 から毎回出ます。
- OSで「視差効果を減らす」を選んでいる人には 1・2・4・5 を出さず、飾りも動かしません。
- 読み込みに失敗しても、4秒で黒い画面は外れます。

| ファイル | 役割 |
|---|---|
| `index.html` の `<head>` 内スクリプト | パラメータの判定、黒い画面を先に出す、ファイルの読み込み |
| `assets/js/halloween.js` | 演出と飾り |
| `assets/css/halloween.css` | 演出と飾りの見た目 |
| `assets/css/style.css` の「ハロウィン仕様の幕」 | 読み込み前の黒い画面と、FVの登場演出の一時停止 |
| `assets/js/motion.js` の雪の色 | ハロウィン中はオレンジと紫 |

期限は設けていません。パラメータを付けたURLを配る期間で運用します。季節が終わって不要になったら、`halloween.js` / `halloween.css` を消し、`<head>` 内のハロウィン部分と `style.css` の「ハロウィン仕様の幕」を削除します（消さなくても、パラメータなしのアクセスには影響しません）。

## 講座を追加・差し替える

新しい講座は、次の3か所に同じ正式名称・日数・校舎で追加します。講座カードの一覧（`.spec`）は「開催日・時間・受講料」の3項目です（参加条件・作るものは載せない方針）。概要が未着のあいだは「講座の概要は準備中です」と書き、講座名から内容を補いません。

1. 講習会紹介の `article.course`（校舎ごとの `.campus-group` の中）
2. 料金表の `tr`（`td` には `data-label` を付ける）
3. スケジュールの開催枠（下のひな形）

未確定の項目は `<dd class="pending">準備中</dd>` と書くと、点線の「準備中」バッジで表示されます。

ID は重複させません。例: `course-04`、`price-course-04`。

カードから料金行へは `#price-course-04`、日程が1枠ならその枠の id へリンクします。


## 料金を変える

`#pricing` の表を編集します。

- 金額は税込で書く。税別と混ぜない。税の加算はしない。
- 未確定のセルは「準備中」または「未指定」のままにする。仮の数字は置かない。
- 複数申込料金は、指定された講座だけに書く。必要講座数や校舎をまたぐ条件は、確認前に決めない。
- JavaScript でタイピングゲームを作ろう！の複数申込料金は未指定です。「割引なし」とは書きません。
- 会員生と一般生が同額なら、料金列は1つ。
- 割引を載せるときは、対象・条件・割引後の金額を同じ表の近くに書く。前年の複数申込割引や友人紹介は、運営が確認するまで載せない。
- 教材費、PC、キャンセル条件が決まったら、表の下のリストを更新する。

## 日程を追加する

`#schedule-list` の中へ、日付の早い順に貼ります。校舎は `kyodai`（京大本校）か `umeda`（梅田校）だけです。

```html
<article
  class="session"
  id="session-kyodai-course-01"
  data-session
  data-campus="kyodai"
  data-status="preparing"
  data-course-id="course-01"
  data-deadline="2026-12-20T23:59:59+09:00"
  data-end="2026-12-23T17:00:00+09:00"
  aria-labelledby="session-kyodai-course-01-title"
>
  <div class="session__dates" aria-hidden="true">
    <span class="day"><span class="day__md">12/22</span><span class="day__wk">火</span></span>
    <span class="day"><span class="day__md">12/23</span><span class="day__wk">水</span></span>
    <span class="session__span">2日間</span>
  </div>
  <div class="session__main">
    <div class="session__top">
      <span class="chip chip--kyodai chip--sm">京大本校</span>
      <span class="status status--preparing" data-status-label>準備中</span>
    </div>
    <h3 id="session-kyodai-course-01-title" class="session__title">ここに正式な講座名</h3>
    <ul class="session__when">
      <li><time datetime="2026-12-22">2026年12月22日（火）</time><span>10:00〜17:00</span></li>
      <li><time datetime="2026-12-23">2026年12月23日（水）</time><span>10:00〜17:00</span></li>
    </ul>
    <p class="session__meta">全日程への参加が必要な場合だけ、その条件をここに書きます。確認前は書きません。</p>
    <p class="session__meta">申込締切: 2026年12月20日（日）23:59</p>
    <button type="button" class="btn btn-cta btn--sm" data-session-cta disabled>申込準備中</button>
  </div>
</article>
```

梅田校なら `data-campus="umeda"` と `chip--umeda` にします。日曜日は `day` に `day--sun` を足すと赤丸になります。曜日はカレンダーで確認します。年をまたぐ場合は 2027年と書きます。

`data-status` は次のいずれかです。

| 値 | 表示 | 申込 |
|---|---|---|
| `preparing` | 準備中 | 停止 |
| `open` | 受付中 | 確認済みのフォームへ |
| `full` | 満席 | その枠だけ停止 |
| `closed` | 受付終了 | 停止 |
| `cancelled` | 中止 | 停止 |

受付中にするときは、ボタンを次のリンクに変えます。ラベルには校舎・講座・日程を入れます。フォームが枠の事前選択に対応していると確認できるまで、パラメータは付けません。

```html
<a
  class="btn btn-cta btn--sm"
  data-session-cta
  href="https://（確認済みの冬の講習会フォーム）"
>
  京大本校・講座名・12月22日（火）から参加を申し込む
</a>
```

日時は `+09:00` を付けます。付けない場合も、JavaScript は日本時間として解釈します。`data-status="open"` のまま締切または終了時刻を過ぎると、表示上は受付終了に切り替わります。正式な終了時は HTML の `data-status` も `closed` に更新してください。

開催枠が1件もないあいだは「スケジュールは準備中」と出ます。掲載後に、選んだ校舎の枠が0件なら「現在公開中の日程はありません」と出ます。

初期表示は「関西2校舎すべて」です。

## 申込ボタンを有効にする

フォーム URL が確定するまで、主ボタンはリンクにせず「申込準備中」のままにします。

有効にする場所は次の5つです。すべて同じ URL、同じタブで開きます。

- ヘッダー
- ファーストビュー
- 料金の直後
- スケジュールの末尾
- スマートフォン下部の固定ボタン

各ボタンを、無効な `button` から次へ置き換えます。

```html
<a class="btn btn-cta" href="https://（確認済みの冬の講習会フォーム）">冬の講習会に申し込む</a>
```

ヘッダーは `btn--sm header-cta` のクラスを残します。

あわせて、FV下の `#apply-note`（「申込フォームは現在準備中です」）と、料金・スケジュールの `.apply-band__text` の文を、受付中であることが分かる文に変えます。

受付終了後は、リンクをやめて「受付は終了しました」と表示します。

冬合宿の案内カードは、運営判断で掲載しないことにしました（要件定義 4.2 から変更）。

## 公開

1. 公開リポジトリと管理者を決める。
2. `main` のルートに `index.html` と `.nojekyll` がある状態で GitHub Pages を有効にする。
3. 公開 URL が決まったら canonical と OGP を設定する。
4. 画像、CSS、JavaScript、申込リンクが 404 にならないことを確認する。
5. 検索に出したくないあいだは `noindex, follow` のままにする。これは閲覧制限ではありません。

計測タグは、運営が基盤と ID を指定した場合だけ追加します。個人情報は送らないでください。

## 公開前チェック

- タイトル、OGP、フッター、フォームが 2026年冬の関西版である
